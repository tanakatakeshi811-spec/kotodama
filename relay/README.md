# コトダマ中継サーバー（APIキーなしで、PCのClaudeを使う）

GitHub Pages のコトダマ（https://tanakatakeshi811-spec.github.io/kotodama/）から、**このPCにログイン済みの Claude Code** を呼ぶための小さなサーバーです。APIキーは要りません。使った分は、Claude の使用量に数えられます。

```
コトダマ（ブラウザ） → 中継サーバー（このPC） → claude -p（ログイン済みClaude Code） → 答えをそのまま返す
                ↑ 同じPCなら http://127.0.0.1:8787
                ↑ スマホなど外からは Cloudflare Tunnel（https://〜.trycloudflare.com）経由 ＋ 合言葉
```

## A. このPCだけで使う（かんたん）

1. 一度だけ：Node.js（18以上）と Claude Code を入れて、`claude` でログインしておく
2. `start-relay.bat` をダブルクリック（黒い窓が開く。**開いている間だけ**使える）
3. コトダマを開く。つながると「AIにつながっていません」の案内が消える（先に開いていたら、設定 → 接続 →「接続を試す」）

## B. スマホなど外からも使う（Cloudflare Tunnel ＋ 合言葉）

1. `relay/passphrase.txt` に**合言葉を1行だけ**書く（このファイルはGitに載せない設定。公開リポジトリには置かないこと）
2. `cloudflared.exe`（Cloudflare公式）を `server.mjs` と同じフォルダに置く（無ければ PATH の `cloudflared` を探す）
3. `start-relay-tunnel.bat` をダブルクリック。黒い窓に「外からつながる住所」と、スマホで開くリンクが出る
4. スマホでそのリンクを開く → 住所が自動で入る。設定 → 接続 で**合言葉を入れて「接続を試す」**（以後はその端末に覚えさせる）
5. 終わったら黒い窓を閉じる。トンネルも一緒に止まる

- 住所は起動のたびに変わる（無料の一時トンネルのため）。起動するたびに、表示されたリンクをスマホで開き直す
- 合言葉が未設定のときは、外には公開しない

## 守っていること

- 待ち受けは `127.0.0.1` だけ。外からの要求はトンネル経由でしか届かない
- 許可する画面は `https://tanakatakeshi811-spec.github.io` と `localhost` だけ。ほかのサイトからの呼び出しは断る（環境変数 `ORIGINS` で変えられる）
- トンネル経由の要求には合言葉が必須。5回まちがえた相手は15分ロック、全体で1時間に30回まちがえると止まる
- Claude Code には道具（ファイル操作など）を一切渡さず、設定も読ませない。会話のテキストを返すだけ
- 同時に処理するのは3件まで

## できないこと・注意

- PCが起動していて、黒い窓が開いている間だけ使える
- 画像は送れない（名前だけがAIに伝わる）
- 合言葉は短い数字だと推測されやすいので、できれば長めに。住所（ランダムな長い名前）を知られなければ、まず届かない
- Chrome で「ローカルネットワークへのアクセス」を聞かれたら許可する。Safari は https のページから http のローカルへの通信を止めることがある（外から使うトンネル方式なら https なので問題なし）
