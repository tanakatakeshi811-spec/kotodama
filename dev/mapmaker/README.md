# マップ制作（コトダマ）の開発用ファイル

アプリ本体は **リポジトリ直下の `index.html` が正**（1ファイルで完結・ビルド不要）。
このフォルダは、マップ制作を作ったときの「分割ソース」と「自動テスト」の控えです。`index.html` を直接直してもかまいません（その場合、ここは古くなります）。

## 中身

| 場所 | 役割 |
| --- | --- |
| `src/01_core.js` 〜 `99_end.js` | マップ制作のモジュール。番号順につなぐと `const MapMaker = (() => { … })();` になる |
| `src/mm.css` | マップ制作の見た目（`/* mm:start */` 〜 `/* mm:end */` として `</style>` の前に入る） |
| `src/patches.py` | コトダマ本体へのつなぎ込み。「本体のここ1か所だけに一致する文字列 → 差し替え後」の一覧 |
| `build.py` | マップ制作を入れる前の `index.html` に、上の3つを組み込んで1つのHTMLにする |
| `tests/` | ヘッドレスChromium（Playwright）の自動テスト。外のネットワークは `tests/mocks.js` の偽物 |
| `lint.py` | 公開用 `index.html` の構文と未定義変数のチェック |

モジュールの中身：`01_core`=保存(Store)・共通 / `02_osm`=OpenStreetMap(Nominatim・Overpass)と気温(Open-Meteo) / `03_layout`=建物内の見取り図の目安 / `04_assemble`=地図データの組み立て / `05_sample`=見本 / `06_render`=Canvas2Dの斜め投影3D / `07_view`=カメラ・操作 / `08_gen`=AIで下調べ＋お店リストを作る流れ / `09_lib`=ライブラリ・作成ダイアログ / `10_view`=ビューア画面（2D/3D・検索・カード・気温・GPS） / `11_act`=ボタンの動作・AIチャット・LIVE連携。

## 組み立て直す

```sh
git show a80c267:index.html > base_index.html      # マップ制作を入れる前の版
python3 build.py base_index.html out/index.html    # 公開中の index.html と同じものができる
```

pip install playwright && playwright install chromium

## 本物のネットワークでわかったこと（公開後に確かめた）

偽物では気づけなかったので、手直しの理由として残しておく。

- Nominatim の自由文検索は「チェーン名＋地名」に弱い（「コストコ 幕張」だと別の県のコストコが先頭に出る）。→ `OSMX.search` は、入れた言葉が結果に全部は出てこないとき、地名を先に探して、そのまわり（`bounded=1` の範囲）だけで名前を探しなおす。
- Overpass の公開サーバーは本物だとかなり不安定。overpass-api.de は、混んでいると小さな問い合わせでも30〜45秒待たされ、すぐ 502/504 を返すこともある。ミラー（private.coffee・kumi・maps.mail.ru）は45秒止まったままのことがある。処理が間に合わないと、エラーではなく「空っぽ（途中まで）の結果＋`remark`（runtime error…）」を200で返すことがある（→ 成功にせず次のサーバーへ）。→ `OSMX.overpass`：すぐ断られたサーバーには `retryMs`（2.5秒）後に1回だけ聞き直す／1つめが `hedgeMs`（15秒）たっても答えないとき次のサーバーにも聞き、先に答えたほうを使う（遅かったほうは中止）／同じ種類（`kind`）で前に答えたサーバーから始める。建物・道路と名前のある場所の2本は**同時に**聞く（1本ずつ聞くと、本物では待ちが2倍になった：ららぽーとで約75秒。同時なら約33秒）。同じサーバーへは2本まで。
- OSM では、商業施設の全体や「北館」のような棟が `shop=mall` の別データとして入っていることがある。棟は `building=retail` と名前だけ（`shop` なし）、オフィスのビルは `building=commercial` のことも多い。→ 自分自身・同名のもの、お店の印のない大きな `building=retail`（棟）、名前つきの `building=commercial`（ビル）は「お店」として数えない（小さな売店の建物は残す）。同じ場所の重複（点と面）は1つにまとめて候補に出す。
- 建物の外にあるお店は、階や棟がわからないので「まわりのお店・施設（OpenStreetMap）」にまとめる（位置は OSM の本物）。
- 中継のAIが使えなくなる原因の一つが、中継を動かしているPCの Claude Code の**ログイン切れ**。`claude -p` が毎回「Failed to authenticate: OAuth session expired and could not be refreshed」を返し、中継は `relay_error` として渡してくる（中継そのものとトンネルは生きていて `/ping` も通る）。これを一時的なエラーと同じに扱うと、聞き直しだけで1〜2分待たされたうえ、最後は「場所の名前を変えて試してください」という見当違いのエラーになった。→ `08_gen.js` の `loginWhy` が、この文言・`ai_login`・`api_key`・`session_expired` を「ログイン切れ」と見分け、聞き直さずに OpenStreetMap だけで作る（理由は `map.info.aiDown`＝`relay`/`key`/`session`）。直し方は、PCのターミナルで `claude` を開いて `/login`。直ったあとは「作り直す」でAIの店の一覧も作れる。
